# 📄 DocuForge – AI Document Assistant

DocuForge is an AI-powered document assistant that allows users to upload documents and ask questions about their content.

## 🚀 Features

* 📄 Upload documents
* 🔍 Ask questions about the document
* 🤖 Get AI-generated answers
* 💬 Simple chat interface
* 📚 Answers based on the uploaded document

## 🛠️ Technologies Used

* Python
* Streamlit
* Ollama
* ChromaDB
* Sentence Transformers

## ⚙️ How It Works

1. Upload a document.
2. DocuForge extracts the text.
3. The text is divided into smaller sections.
4. Relevant information is searched when a question is asked.
5. AI generates an answer based on the document.

## ▶️ How to Run

Install the required libraries:

```bash
pip install streamlit ollama chromadb sentence-transformers
```

Run the application:

```bash
streamlit run app.py
```

## 🎯 Purpose

The main purpose of DocuForge is to make it easy for users to understand and interact with their documents using AI.
